资源上的绝对公平可行吗？-暂时只是浅显的对话，之后整理想法

2026-05-10
  1. 推倒重来？绝对的社会主义？
  2. 缝缝补补？相对的平均主义？
  3. 一条路走到黑？多元化的竞争机会？

我想要寻求一个尽可能副作用小的有效消弭这个世界阶级固化死循环的办法。我想到的是取消财产继承制，所有人都不应该为自己的子孙辈奋斗，而是要为人类共同的未来奋斗。所以不管生前积累了多少财富，死后都要进入国库充公。可行吗

我先把问题拆成三层来评估：目标是否成立、手段是否有效、以及副作用是否可控。重点会放在“完全取消继承”与“高强度遗产税/信托限制/机会均等投资”等替代方案的比较。

Thought for 39s

结论：完全取消财产继承、死后一律充公，不是副作用小的方案；它在道德直觉上有力量，但制度上大概率不可行，也不一定有效。
更可行的版本是：保留普通家庭有限继承，但对大额继承、赠与、信托、家族基金会、离岸结构实行强烈累进税，并把税收专门转化为全民“启动资本”或公共教育、住房、医疗机会基金。

你的核心判断是对的：继承是阶级固化的重要机制之一。 OECD 的继承税报告也明确指出，财富不平等长期维持在高位，继承和重大赠与更集中流向富裕家庭，未来随着资产价格和婴儿潮一代老去，继承规模可能继续扩大，从而强化不平等。OECD 也认为继承、遗产和赠与税可以用于增加财政收入、降低不平等、改善机会平等。

但你的具体方案——死后财富全部国库充公——问题很大。

第一，它会强烈刺激规避。真正富人不会等死后再转移资产，而会通过生前赠与、家族信托、私人基金会、保险、低息贷款、离岸公司、提前消费、移民、资产低估等方式把财富提前转出去。2025 年一篇对继承税实证研究的综述指出，继承税引发的行为反应从温和到很大不等，尤其是老年人和超高净值群体反应更强；而且规避、避税、逃税反应往往比真实的劳动或储蓄反应更明显。

第二，它会误伤很多“资产多、现金少”的家庭。比如小企业、农场、家庭住房、未上市股权、艺术品或知识产权。若死后一律充公或强制变现，会导致家族企业断裂、员工失业、资产被低价出售。你本意是打击阶级固化，但执行时容易变成“国家强制清算民间资本”。

第三，它会要求非常强的国家监控。为了防止富人生前转移资产，国家必须追踪大量赠与、信托、境内外账户、关联交易和家庭内部利益安排。制度越彻底，监控越深入。你想消灭阶级固化，但可能换来另一种权力固化：官僚系统掌握财富分配权。

第四，政治上几乎不可持续。继承税本身已经高度不受欢迎。OECD 数据显示，24 个 OECD 国家征收继承税或遗产税，但平均只贡献征收这些税国家总税收的约 0.5%，原因之一就是税基窄、豁免多、规划空间大。澳大利亚现在没有继承税或遗产税；ATO 也明确说明澳洲没有 inheritance or estate taxes。

所以我会这样评价：

你的目标合理；你的工具过猛；过猛之后反而会失效。

更好的制度不是“所有人死后归零”，而是：

允许亲情范围内的有限照顾，但禁止财富无限代际复制。

比较现实的设计可以是：

  1. 设一个较高免税额
    普通家庭继承不动，避免把中产也推到反对面。例如配偶、未成年子女、残障依赖人、普通自住房可有保护。
  2. 对受益人征税，而不是只对遗产整体征税
    更好的模型是 recipient-based inheritance tax：看每个继承人一生累计接受了多少继承和赠与。这样一个孩子继承 50 万与一个孩子继承 5000 万，待遇不一样。
  3. 终身累计赠与 + 继承统一计税
    否则富人会在生前转移。生前大额赠与、低价转让、家族信托分配、保险安排、关联方贷款豁免，都应进入同一套系统。
  4. 高度累进税率，只针对大额代际财富
    比如小额继承低税或免税；超过若干百万后税率上升；超过极高门槛后进入 60%、70%、80% 级别。重点不是惩罚普通父母，而是阻断王朝资本。
  5. 把收入专款用于“全民继承”
    这点最重要。钱不能只是进一般国库。应建立独立基金，让每个年轻人在 18、21 或 25 岁获得一笔启动资本，用于教育、住房首付、创业、技能培训或迁居就业。类似 “universal inheritance / baby bonds” 的思路。已有研究和政策讨论认为，这类一次性资本授予可降低年轻人起点差距，尽管不能单独解决全部财富不平等。
  6. 配套土地、资本利得、住房和教育改革
    只改继承不够。OECD 也明确说，继承税不是 silver bullet，需要配合资本收入税、资本利得税等改革。

我会把你的方案改写成一个更可行的版本：

废除无限继承权，而不是废除全部继承权。
每个人可以从父母那里得到有限的、体面的支持；但没有人应当仅因出生而获得足以支配他人劳动、住房、教育和政治影响力的世袭资本。超过合理上限的代际财富转移，应通过强累进税收回，并转化为全体年轻人的启动资本。

这比“死后全部充公”更有优势：

  • 政治阻力小很多；
  • 普通家庭不容易被动员反对；
  • 规避空间仍然存在，但比 100% 没收少；
  • 更符合人的亲情本能；
  • 目标更精准：打击的是王朝式财富复制，不是普通父母对子女的合理照顾。

最根本的问题是：阶级固化不能靠禁止父母爱子女来解决；只能靠限制爱子女被资本无限放大的能力来解决。

如果对税收系统已经绝望呢？因为总有避税办法。能否有其他不考虑现实阻力，一劳永逸的办法组织前10%的富人继续积累财富

我会直接按“制度工程”回答，不把问题停留在道德层面。关键不是怎么把富人的钱收回来，而是怎么让财富优势无法继续滚雪球、转化为政治权力和代际支配。

Thought for 46s

可以，但要直说：不存在真正“一劳永逸且副作用小”的办法。
要阻止前 10% 继续积累财富，核心不是税，而是改写产权规则。税是事后拿走；产权制度是事前规定“什么东西可以被私人占有、占有到什么程度、能否传给下一代、能否用钱继续买权力”。

全球层面，问题确实严重：World Inequality Report 2026 称，全球前 10% 拥有约四分之三的全球财富，而底部 50% 只拥有约 2%。 但“前 10%”其实太宽。澳洲、美国、西欧很多中上收入专业人士、小企业主、退休房产持有人都会进入本国或全球前 10%。真正形成阶级固化和政治支配的，通常是前 1%、前 0.1%、前 0.01%。

如果完全不考虑现实阻力，比较有效的制度组合是：

1. 设定“个人净财富上限”，超过部分自动转为公共资本

这不是税，而是财产权边界。

例如法律规定：任何自然人直接或间接控制的净资产不得超过某个倍数，比如全国成年人中位净财富的 500 倍或 1000 倍。超过上限的部分，不是课税，而是法律上不承认继续私人所有，自动转入社会财富基金。

关键点是“直接或间接控制”。否则富人会把资产放进公司、信托、基金会、亲属、离岸结构。所以必须穿透 beneficial ownership。FATF 对法律实体和信托的透明度标准正是为了解决实际控制人被隐藏的问题，其建议要求取得充分、准确、及时的实际受益所有权信息。

这套制度理论上最直接，但副作用也最大：
它会强烈打击创业和投资激励，并且需要极强的资产登记、估值、跨境追踪和反规避能力。没有这些，它会变成纸面制度；有这些，它会变成高度监控型国家。

2. 禁止“无限代际传递”，但不禁止普通继承

比完全取消继承更精准的办法是：

每个人一生可以从他人处接受一定额度的赠与和继承；超过额度后，法律不承认私人承接，自动进入社会财富基金。

这比遗产税强，因为它管的是受益人一生累计获得的无偿财富，包括生前赠与、信托分配、保险、低价转让、贷款豁免、基金会利益等。OECD 也认为，按受益人计算的终身财富转移税比单次继承税更公平，也更能减少规避，但复杂度更高。

如果你已经不信任税制，可以把它改成非税模式：
超过终身接受上限的赠与或继承，一律无效。

这会直接切断“我爸妈有钱，所以我天然支配社会资源”的通道。

3. 把大型生产性资本改成“社会所有 + 私人经营”

这可能是副作用相对较小的激进方案。

不是没收所有私人财产，也不是禁止富人生活优越，而是规定某些核心资产不能被无限私人垄断：

  • 土地；
  • 矿产、能源、水资源；
  • 银行和支付基础设施；
  • 医疗、教育、住房基础设施；
  • 互联网平台、数据基础设施；
  • 自然垄断行业；
  • 超大型企业股权。

这些资产可以由企业经营，但最终收益权部分归入全民社会财富基金。每个公民持有不可出售、不可继承、不可抵押的社会资本账户，按年分红。这样不是把钱交给普通财政挥霍，而是让所有人都有资本性收入。

这解决的是根本问题：
穷人只有劳动收入，富人有资本收入。只要资本收益长期高于劳动收入，阶级就会再生产。社会财富基金的目的，是让普通人也拥有资本收益，而不是永远靠工资追资产价格。

4. 强制拆分垄断，阻止财富通过市场权力滚雪球

很多巨富不是因为“勤奋储蓄”，而是因为控制了平台、网络、专利、土地、金融入口或垄断性基础设施。只要垄断存在，财富会自动聚集。

所以需要非常强的反垄断规则：

  • 单一企业市场份额超过阈值即强制拆分；
  • 平台不得同时控制基础设施和自营业务；
  • 禁止排他协议、掠夺性定价、数据封锁；
  • 超大型并购原则上禁止；
  • 对系统性平台实行公共接口义务；
  • 对金融杠杆和资产回购设硬限制。

这比税更根本。税是等巨兽长成后再剪毛；反垄断是阻止巨兽长成。

5. 改公司法：资本收益必须自动分给劳动者和公众

可以规定：任何达到一定规模的公司，每年必须把新增股权或利润的一部分自动分配给：

  • 员工基金；
  • 行业公共基金；
  • 国家/地方社会财富基金；
  • 消费者或数据贡献者基金。

也就是说，企业越成功，私人创始人和投资人仍然发财，但社会也自动持股。这样财富不会全部沉淀到少数资本所有者手中。

这不是传统税收，而是公司产权结构内置分配机制。

6. 禁止财富购买政治影响力

如果不处理政治捕获，任何财富限制制度都会被富人慢慢拆掉。

所以必须有硬规则：

  • 禁止公司政治捐款；
  • 个人政治捐款极低上限；
  • 严格限制游说；
  • 高级官员离任后多年不得进入相关行业；
  • 竞选经费公共化；
  • 媒体所有权集中限制；
  • 政策制定过程强制公开利益关联。

这不是经济分配问题，而是制度保命问题。富人真正可怕的不是有钱，而是用钱改规则。

最接近你想法的制度模型

如果要设计一个“不靠传统税制”的极端但较完整方案，我会写成这样：

财富民主宪章

  1. 每个自然人享有私人财产，但不得直接或间接控制超过法定财富上限的净资产。
  2. 每个自然人一生可接受有限额度的赠与和继承；超过部分不得私人承接，自动归入社会财富基金。
  3. 信托、基金会、离岸公司、代持、关联方安排均按最终控制人穿透认定。
  4. 土地、自然资源、系统性金融基础设施、核心数据平台和自然垄断行业不得永久完全私人化。
  5. 大型企业必须设置员工和社会持股机制。
  6. 社会财富基金按人头建立不可转让账户，使每个人都拥有基础资本收益。
  7. 财富不得购买政治权力；政治融资、游说和媒体所有权受到硬性限制。

这才是“不靠税收”的版本。

但它仍然不是一劳永逸。原因很残酷：

财富不是一个静态存量，而是一种权力关系。
只要人类社会允许交换、创新、组织、声望、知识、风险承担和权力协调，就一定会产生差异。问题不可能是“永久消灭富人”，只能是：

  1. 防止富人变成世袭贵族；
  2. 防止资本收益无限压倒劳动收益；
  3. 防止财富购买法律和政治；
  4. 防止基础生活机会被资产阶级垄断；
  5. 让所有人拥有最低限度的资本所有权。

所以最终答案是：

如果你对税收彻底绝望，最有效的替代方案不是更高税率，而是“财产权上限 + 继承承接上限 + 社会财富基金 + 强反垄断 + 政治去金权化”。

但也要承认：
这已经不是温和改良主义，而是产权宪法重写。它比单纯遗产税更有效，也比全部没收更精确；但它绝不可能没有副作用。真正低副作用的目标，不是阻止前 10% 继续变富，而是阻止前 1%/0.1% 把财富变成永久统治权。
